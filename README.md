# MouseRoaming 跨平台滑鼠鍵盤與剪貼簿無縫共享系統

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | [English](README.en.md)

MouseRoaming 是一套專為 **Windows 11** 與 **macOS** 設計的高效能、低延遲跨平台滑鼠、鍵盤與剪貼簿無縫漫遊工具。如同 Barrier / Synergy，但採用現代 **Rust** 重寫，具備更安全現代化的 **TLS 1.3** 加密連線、可視化**拖曳螢幕排列**以及原生作業系統圖示識別。

---

## ✨ 核心特色

1. **跨平台無縫漫遊 (Windows ↔ macOS)**
   - 滑鼠移至螢幕邊緣即時流暢穿透至另一台主機。
   - **游標自動隱藏**：當本機滑鼠漫遊至遠端主機操作時，本機端游標自動隱藏不見；游標返回本機時立即恢復顯示。
   - 支援微調防誤觸邊角死區（Dead Corners）與防止來回彈跳的冷卻機制。

2. **直覺的視覺化拖曳螢幕排列 (Drag-and-Drop Topology)**
   - 以 Windows 11 圓角微軟視窗圖示與 macOS 蘋果燈號視窗圖示呈現各裝置。
   - 圖示下方清楚顯示主機名稱（Hostname）與區域網路 IP 位址。
   - 支援以滑鼠**拖曳定位**至上／下／左／右，並在拖曳靠近時提供磁吸預覽；重疊放置時自動互換（Swap）位置；拖曳至下方停靠區即可解除定位。

3. **智慧按鍵與滾輪映射**
   - **Ctrl ↔ Command (⌘) 自動互換**：在 Windows 上按 `Ctrl+C` / `Ctrl+V`，傳送到 Mac 自動轉換為 `Cmd+C` / `Cmd+V`。
   - **滾輪方向反轉補償**：抵銷 macOS 自然捲動習慣差異。
   - **雙向剪貼簿即時同步**：支援 UTF-8 文字跨主機無感複製貼上（單次上限 2 MB，內建防回音環迴抑制）。

4. **安全與探索**
   - **TLS 1.3 傳輸加密**：自動產生 Ed25519/ECDSA 自簽憑證，首次連線 TOFU（Trust-On-First-Use）指紋驗證與可選配對碼（Pairing Token）。
   - **mDNS 區網自動探索**：自動掃描同一區網內運作中的 MouseRoaming 裝置，一鍵完成信任與連線。
   - **硬體級緊急逃生鍵**：任何時候按下 `Ctrl + Alt + Esc`，立即解除遠端攔截鎖定，強制游標與鍵盤控制權返回本機。

## 🚀 快速上手

### 系統需求
- **Windows**：Windows 10 / 11 (x64)
- **macOS**：macOS 12 Monterey 或更高版本（支援 Apple Silicon M 系列及 Intel）
- 兩台電腦需位於同一個區域網路（LAN / Wi-Fi）。

### 安裝與啟動

#### 方式一：直接執行編譯產物
```bash
cargo build --release
# 執行執行檔
./target/release/mouseroaming
```

#### 方式二：命令列與背景服務模式
```bash
# 作為主控端 (Server / 分享實體鍵鼠)
mouseroaming --role server --port 24850

# 作為受控端 (Client / 接收輸入)
mouseroaming --role client --connect 192.168.1.100:24850

# 無 GUI 視窗背景運作 (Daemon / Headless)
mouseroaming --headless --role client --connect 192.168.1.100:24850
```

## 🖥 介面操作說明

### 1. 總覽與螢幕排列頁籤
- **中央本機 (This PC)**：顯示本機的作業系統圖示、裝置名稱與區網 IP。
- **邊緣槽位**：顯示各方向目前指派的遠端電腦。
- **拖曳操作**：
  - 按住畫布上或下方「已連線裝置」中的任何裝置卡片進行拖曳。
  - 拖至目標邊緣時會出現發光外框與磁吸虛線，放開即可綁定。
  - 若目標邊緣已指派其他電腦，放開後兩台電腦會**自動對調位置**。
  - 拖回下方「已連線裝置」區域放開，即可解除該裝置的螢幕定位。
- **捷徑操作**：
  - **雙擊裝置圖示**：滑鼠游標立即切換至該裝置。
  - **右鍵選單**：可快速切換、指定位置或解除定位。

### 2. 區網探索頁籤
- 自動掃描同網段的 Server 裝置。
- 顯示裝置名稱、OS 類型、IP 及 TLS 憑證指紋，點擊「一鍵連線」即可完成配對。

### 3. 設定頁籤
- 可切換角色（Server 或 Client）。
- 勾選是否開啟 Ctrl ↔ Command 轉換、反轉滾輪、剪貼簿同步。
- 調整防誤觸死區大小與冷卻時間。

## 🔒 系統權限需求

- **macOS**：初次啟動時需在「系統設定 → 隱私權與安全性 → 輔助使用」與「輸入監控」中允許 MouseRoaming。
- **Windows**：若需控制以「系統管理員身分執行」的視窗（如工作管理員），請以管理員身分啟動 MouseRoaming（受 Windows UIPI 機制限制）。
