# MouseRoaming 跨平台鼠标键盘与剪贴板无缝共享系统

[繁體中文](README.md) | [简体中文](README.zh-CN.md) | [English](README.en.md)

MouseRoaming 是一套专为 **Windows 11** 与 **macOS** 设计的高性能、低延迟跨平台鼠标、键盘与剪贴板无缝漫游工具。类似于 Barrier / Synergy，但采用现代 **Rust** 编写，具备更安全现代化的 **TLS 1.3** 加密连接、可视化**拖曳屏幕排列**以及原生操作系统图标识别。

---

## ✨ 核心特色

1. **跨平台无缝漫游 (Windows ↔ macOS)**
   - 鼠标移至屏幕边缘实时流畅穿透至另一台主机。
   - **光标自动隐藏**：当本机鼠标漫游至远端主机操作时，本机光标自动隐藏；光标返回本机时立即恢复显示。
   - 支持微调防误触边角死区（Dead Corners）与防止来回弹跳的冷却机制。

2. **直观的可视化拖曳屏幕排列 (Drag-and-Drop Topology)**
   - 采用 Windows 11 圆角微软视窗图标与 macOS 苹果灯号视窗图标呈现各设备。
   - 图标下方清晰显示主机名称（Hostname）与局域网 IP 地址。
   - 支持以鼠标**拖曳定位**至上／下／左／右，并提供磁吸对齐预览；拖至已占用的边缘时自动互换（Swap）位置；拖回下方停靠区即可解除定位。

3. **智能按键与滚轮映射**
   - **Ctrl ↔ Command (⌘) 自动互换**：在 Windows 上按下 `Ctrl+C` / `Ctrl+V`，发送至 Mac 自动转换为 `Cmd+C` / `Cmd+V`。
   - **滚轮方向反转补偿**：抵消 macOS 自然滚动的习惯差异。
   - **双向剪贴板即时同步**：支持 UTF-8 文本跨主机无感复制粘贴（单次上限 2 MB，内置防回音环回抑制）。

4. **安全与探索**
   - **TLS 1.3 传输加密**：自动生成 Ed25519/ECDSA 自签证书，首次连接 TOFU（Trust-On-First-Use）指纹验证与可选配对码（Pairing Token）。
   - **mDNS 局域网自动探索**：自动扫描同局域网内运行中的 MouseRoaming 设备，一键完成信任与连接。
   - **硬件级紧急逃生快捷键**：任何时候按下 `Ctrl + Alt + Esc`，立即解除远端拦截锁定，强制光标与键盘控制权返回本机。

## 🚀 快速上手

### 系统需求
- **Windows**：Windows 10 / 11 (x64)
- **macOS**：macOS 12 Monterey 或更高版本（支持 Apple Silicon M 系列及 Intel）
- 两台电脑需处于同一个局域网（LAN / Wi-Fi）。

### 安装与启动

#### 方式一：直接运行编译产物
```bash
cargo build --release
# 运行可执行程序
./target/release/mouseroaming
```

#### 方式二：命令行与后台服务模式
```bash
# 作为主控端 (Server / 分享实体键鼠)
mouseroaming --role server --port 24850

# 作为受控端 (Client / 接收输入)
mouseroaming --role client --connect 192.168.1.100:24850

# 无 GUI 窗口后台运行 (Daemon / Headless)
mouseroaming --headless --role client --connect 192.168.1.100:24850
```

## 🖥 界面操作指南

### 1. 总览与屏幕排列页签
- **中央本机 (This PC)**：显示本机的操作系统图标、设备名称与局域网 IP。
- **边缘插槽**：显示各方向当前绑定的远程电脑。
- **拖曳操作**：
  - 按住画布上或下方“已连接设备”中的任意设备卡片进行拖曳。
  - 拖至目标边缘时会出现发光外框与磁吸虚线，松开即可绑定。
  - 若目标边缘已指派其他设备，松开后两台设备会**自动对调位置**。
  - 拖回下方“已连接设备”区域松开，即可解除该设备的屏幕定位。
- **快捷操作**：
  - **双击设备图标**：鼠标光标立即切换至该设备。
  - **右键菜单**：可快速切换、指定位置或解除定位。

### 2. 局域网探索页签
- 自动扫描同网段的 Server 设备。
- 显示设备名称、操作系统类型、IP 及 TLS 证书指纹，点击“一键连接”即可完成配对。

### 3. 设置页签
- 可切换角色（Server 或 Client）。
- 勾选是否开启 Ctrl ↔ Command 转换、反转滚轮、剪贴板同步。
- 调整防误触死区像素与冷却时间。

## 🔒 系统权限需求

- **macOS**：首次启动时需在“系统设置 → 隐私与安全性 → 辅助功能”与“输入监控”中允许 MouseRoaming。
- **Windows**：如需控制以“管理员身份运行”的窗口（例如任务管理器），请以管理员身份启动 MouseRoaming（受 Windows UIPI 机制限制）。
